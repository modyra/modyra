Rules the control carries

        

          A rule is declared once and the native control learns it: the code below carries
          maxlength and pattern because its rules say so — nothing wrote
          those attributes. Leave a required field empty and the message appears in space that was
          already reserved, so nothing under it jumps.
        

        

        

      


      

        
A section that only counts sometimes

        

          The company details above are declared like everything else and are
          out of play while the account is personal: not validated, not submitted,
          and what was typed into them kept. Switch the account type and watch the verdict change
          without the values moving.
        

      


      

        
Rows keyed by data

        

          A table rendered by column: the two controls of one row are created in
          different places and at different times. Rows enter and leave edit mode, the table sorts,
          and a provisional key becomes a real one — none of it touches a value or the verdict.
        

        

        

      


      

        
A checkout its backend defined

        

          This form is not written in the page. A Rust service builds it from its own business
          objects, hands it over as contract JSON, and the page parses it
          strictly before drawing a single control — a document off a network is
          data from somewhere else, even when the somewhere else is ours.
