Method

Each project is compiled 5 times with each compiler, alternating between them, and reported by median so a cold file cache on the first run does not decide the result. Both compilers write to a temporary directory, never to dist, and read the same workspace declarations. The Angular package is absent: it is compiled by ng-packagr, whose peer range stops below TypeScript 7.

Regenerate with npm run benchmark:typescript. The raw numbers are in benchmarks/typescript-compilers.json.
